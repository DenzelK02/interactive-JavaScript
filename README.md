# interactive-JavaScript
Interactive JavaScript. Build javascript so user can interact such as webcam, clapping, sound, and etc. 
## Installation Instructions

1. Download or clone this repository.
2. Open the project folder.
3. Make sure the HTML, JavaScript, and any library files are in the same folder.
4. Open `index.html` in a web browser.

## Usage Instructions

1. Open `index.html`.
2. Move the mouse or trackpad around the canvas.
3. Watch the shapes move, rotate, or respond to the mouse position.

## Technologies Used

- HTML
- CSS
- JavaScript
- p5.js
- HTML5 Canvas
